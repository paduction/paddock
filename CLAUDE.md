# Paddock

@AGENTS.md

## Claude Code

- `/paddock-setup` — installs Paddock for someone's home: discovers their Home Assistant, writes and checks
  `paddock.yaml`, deploys with their agreement.
- `/paddock-develop` — the checklist for changing Paddock itself (new setting, new screen, new text).

Use the first when the person talks about *their home*, the second when they talk about *the code*.
